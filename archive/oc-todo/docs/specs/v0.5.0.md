# oc-todo v0.5.0 — detail-inspector panel

Baseline: v0.4.0 (`75ff952`). Delta: a read-only `session.panel` inspector for the
current session's todos, for the CLI plugin only. **No server change, no contract
change, no new storage.** The item shape is unchanged. This is ROADMAP Tier 2 #8
(TUI interactivity), scoped to inspection (no in-place mutation).

## Why

The sidebar is intentionally lossy: each row is clipped to 28 cells and shows only
a notes **count**, never the note text or the metadata. The `todo` tool can print
everything, but there was no way to browse a single todo's full detail in the TUI.
This slice adds a deliberate, keyboard-driven inspection surface over the same
store the sidebar and the `todo` tool read.

## Where it lives

`tui.tsx` (the CLI plugin). A contribution to the `session.panel` slot, opened by
a slash command. The panel owns no state beyond its local selection index; every
read goes through the existing `todo.list` RPC.

## Layout

```
+--------------------------+-----------------------------------------+
| LIST (left, 30%)         | METADATA (top-right, maxHeight 25%)      |
|                          |-----------------------------------------|
| > O write docs           | PROSE (bottom-right, flexGrow 1)         |
|   ~ review pr            | full content + notes, width-wrapped      |
+--------------------------+-----------------------------------------+
| footer: 1/4 . up/down select . esc close                          |
+-------------------------------------------------------------------+
```

- **Left (width `30%`):** one row per todo, in stored order. Row text is
  `<gutter><mark> <value>`, where `gutter` is `\u25B8` for the selected row and a
  space otherwise, `mark` is the sidebar's single-cell status mark, and `value` is
  the content plus the sidebar's notes suffix, clipped to the column. The selected
  row wears `theme.background.raised.high`; closed rows are `theme.text.muted`.
- **Metadata (top-right, `maxHeight="25%"`, `flexShrink={0}`):** fixed label
  column (8 cells), one row per field: `id`, `status`, `priority`, `created`,
  `updated`, `notes`. Timestamps are absolute (UTC, `YYYY-MM-DD HH:MM:SSZ`); a
  non-finite/absent timestamp reads `unknown`.
- **Prose (bottom-right, `flexGrow={1}`):** the full `content`, then a blank line,
  then each note prefixed `- `. Every line is wrapped to the column so no row
  overflows the panel.

The host owns sizing and focus; the panel only fills its box.

## Keys

Registered from inside the panel component, so they are live only while the panel
owns input (an inline plugin layer, not a `cli.json` keybind ID):

| Binding        | Action                                   |
| -------------- | ---------------------------------------- |
| `up` / `k`     | move selection up (clamped at the top)   |
| `down` / `j`   | move selection down (clamped at bottom)  |
| `escape` / `q` | close the panel                          |

Selection is **clamped**, never wrapped. It is tracked by index and re-clamped on
refresh, so a live update cannot leave it out of range; opening the panel resets
it to 0 unless the command argument selected an item.

### Close hint and focus

The one-line footer always states the position and how to close, because the keys
are dead until the panel owns input:

- focused: `2/3 · up/down select · click a row · esc close`
- unfocused: `2/3 · click to focus first · esc close`

Clicking anywhere in the panel focuses it (`panel.focus()` on the root), and
clicking a left-list row selects it. There is deliberately **no** full-screen
toggle: the host owns presentation and already full-screens a narrow terminal, so
an `f` binding would be a near-no-op.

## Command

A single named command, `oc-todo.inspect`, group `Session`, in the palette, with
`slash: { name: "show-todos", arguments: true }`:

- Opens only from a session (else a warning toast `Open a session first`).
- Opens with `context.ui.panel.open("oc-todo.inspect")` (default `panel`
  presentation; the host keeps narrow terminals full-screen).
- The optional argument preselects an item: a decimal argument is a 1-based index;
  otherwise it is resolved as an exact id, then a unique id prefix. An
  unresolved/empty argument selects the first row.

## Data

Reuse the existing read path: `client.rpc(Todo).list({ sessionID })`. Refresh on
`rpc.todo.changed` and keep the sidebar's 3-second poll fallback. The sidebar and
the panel share one feed (one signal, one subscription, one timer) so a single
session is never fetched twice.

Scope is the **current session only** (v1). Cross-session `todo.open` mode is
deferred.

## Pure renderer (tested)

Kept out of the JSX, matching the `sidebarLines` pattern:

- `clampIndex(index, length)` / `moveSelection(index, delta, length)` — selection
  math, tolerant of an empty list and non-finite input.
- `listRows(todos, { selected, width })` — the left rows (`{ text, muted, selected }`).
- `metadataLines(todo | undefined, { width })` — the metadata rows.
- `proseLines(todo | undefined, { width })` — the wrapped content + notes.
- `wrapText(text, width)` — cell-width-aware word wrap with hard-break of an
  over-long word.
- `formatStamp(ms)` — the absolute timestamp text, or `unknown`.
- `resolveSelection(todos, selector)` — the command argument to an index.
- `inspectorFooter(total, selected, focused)` — the focus-aware close hint.
- `listColumnWidth(panelWidth)` / `detailColumnWidth(panelWidth)` — the two column
  budgets (padding-accounted, floored at a minimum).

Every emitted glyph is one cell (`Bun.stringWidth(char) === 1`); new glyphs are
written as `\uXXXX` escapes.

## Acceptance criteria

- Panel opens from a session via `/show-todos`, closes cleanly on `esc`/`q`; disabling
  the plugin removes the contribution.
- Up/down (and `j`/`k`) move the selection and the right panes follow it.
- The footer always says how to close, and reads `click to focus first` while the
  panel is unfocused (its keys are dead until it owns input); clicking focuses the
  panel and clicking a row selects it.
- Metadata pane is bounded to ≤25% of the panel height; prose takes the rest; no
  rendered row exceeds its column width.
- Reads the real store (same data as the `todo` tool and the sidebar) and refreshes
  on `rpc.todo.changed`.
- `bun run check` green; new pure-function tests for the layout/selection/wrap
  logic; the existing suite still passes.
