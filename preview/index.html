One CEO.
A lead.
A stack of employees.

One agent doing everything holds context it does not need, approves its own work, and forgets what it finished the moment context compacts. This stack splits the work into seats, puts the contract on disk, and makes every claim carry a command.

The loop

Eight steps, one direction. The state that survives a compaction is on disk, not in the conversation.

01

Intake

Restate the objective in one sentence. Name the unknowns you would otherwise guess.

02

Rank

Cut into seams. Score value × risk ÷ effort. Keep three live; park the rest with a reason.

03

Brief

Out, Check, Owns. The tool refuses a hole, and nothing is written.

04

Dispatch

One employee per seam, disjoint paths proved first. The prompt carries a path, not history.

05

Reconcile

Read the report before chat. Re-run the cheap check yourself. A claim is not evidence.

06

Land

One commit, plain words, the check output in the body. Mark the seam landed.

07

Digest

Needs you / New / In progress. Every row aged, so a stall is visible without asking.

08

Audit

A context that wrote none of it gives the verdict. The author's check is smoke.

Five tools, no infrastructure

Local files and git. No MCP handshake, no daemon, no network call, no dependencies. Each tool can refuse, which is the point.

ledger

Appends one stamped line. Reads the tail. Rewrites the digest from the record instead of from memory.

brief

Writes a seam contract. Refuses a brief missing Out, Check, or Owns, and writes nothing.

Runs the repo's proving commands and binds pass or fail to a specific HEAD.

04

What it refuses

A system is defined by what it will not do. These are enforced by code, not by prose a model can skip under pressure.

✕
A brief with a holeNo Out, no Check, or no Owns means no file, no dispatch, no work.
✕
Green from another headA check that ran before HEAD moved is stale, and the gate says which two shas disagree.
✕
A seam with no reportOutcome, Evidence, Unverified, Scope, Lesson. The report is not optional paperwork.
✕
A quiet wideningAny path outside Owns is named. It needs its own brief or a line explaining why it belongs.
✕
A worker who delegatesThe employee agent denies the subagent action outright. One seat, one writer.
✕
The author's own verdictA verdict comes from a context that wrote none of the work. Otherwise it is smoke, and marked as such.

Memory on disk

Conversation memory does not survive compaction. Controllers that lost their place have re-run entire finished sequences, the most expensive failure this system exists to prevent.

The soul, four laws
L1
Name the unknown before you spend a token.Assumptions stated. Two readings put on the table. Stop when the picture is unclear.
L2
The smallest change that closes the seam.No speculative flexibility. Two hundred lines that could be fifty is fifty.
L3
Touch only your seam.Every changed line traces to the ask. Orphans you made, you delete.
L4
Prove it, or say you did not.Success is a check that can go red. Unverified: is a first-class line.
