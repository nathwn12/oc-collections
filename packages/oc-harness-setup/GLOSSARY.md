# Starter glossary

**brief** — The four-field contract of objective, output format, tool/source guidance, and boundaries bounding one worker to one artifact and one check.
  Not a task description or prompt; it is what makes a seam dispatchable.
**canon** — The locked tier of primary sources a load-bearing claim must come from.
  Not a reading list or bibliography of everything consulted.
**capability envelope** — The reach an agent is allowed: what it may read, write, run, and fetch.
  Not a role, personality, or craft specialty.
**doctor** — The install-time gate (`scripts/harness-doctor.ps1`) checking the pack's shape laws.
  Not a prose enforcer; it gates what was installed, never how a sentence reads.
**drift** — A rule or fact that aged out of agreement with the tree, accepted openly.
  Not a regression; only a doctor FAIL is a regression.
**enforced vs instructed** — The split between a rule backed by a denying mechanism and a rule stated as prose that may drift.
  Not a severity scale; only the enforced side can deny.
**evolve** — The smallest deliberate extension of the harness: a skill, command, reference, seat, or config change, never a niche one-off.
  Not a niche one-off or a user-local tweak.
**finding** — An audit result citing a canon source or a contradiction between two starter files.
  Not an opinion or suggestion.
**gate** — A runnable check that must exit 0 before work is called done.
  Not a review comment or a check that cannot fail.
**instructed** — A rule stated as prose with no denying mechanism behind it, so drift is accepted openly.
  Not ignored or optional; it still binds, it just cannot deny.
**integration point** — The place where disjoint parallel work is reconciled before a verdict.
  Not a branch or merge commit.
**lane** — One dispatched unit of parallel work with its own artifact and check.
  Not a queue or a lock.
**lessons** — The scar file of operational rules extracted from failures, each recorded once.
  Not a changelog, diary, or summary of what happened.
**non-rule** — Something the starter deliberately does not do, recorded to stop it being re-added.
  Not an omission or to-do.
**proving check** — The runnable check on real inputs whose cited output proves a seam is done.
  Not a review comment or a check that cannot fail.
**reach class** — A distinct set of permitted surfaces that justifies its own agent.
  Not a job title or craft specialty.
**return budget** — The size limit on a worker's return, keeping raw reads in the child.
  Not a token budget for the whole run.
**seam** — An independent unit of work with its own artifact and its own proving check.
  Not a file, step, or task, and not a brief; the brief is the contract around it.
**seat** — An agent holding one reach class.
  Not a job title or craft specialty.
**state** — The per-session markdown record under `state/` that lets a fresh session resume.
  Not the vendor's session store, and not YAML.
**state-seed** — The starter files setup lays down so a fresh install has somewhere to record.
  Not live session state; the first real session overwrites it.
**supply vs surface** — The vendor skill tree is supply invoked on demand while the starter skills are surface always named in the router.
  Not a quality ranking.
**ticket** — One frozen slice of a spec stating what it delivers plus its blocking edges.
  Not a seam without a proving check.
**tier** — The cost band a seat inherits: cheap bulk vs costly verdict.
  Not a model name or a price list.
**UNVERIFIED** — Said aloud when a claim could not be resolved from a primary source.
  Not a citation; never present a gap as a sourced fact.
**vendor skill** — An upstream skill that is supply invoked on demand, never a rule.
  Not surface; never outranks a shipped skill.
**verdict** — A pass/fail on the work from an agent that did not author it, with cited evidence.
  Not a review comment or summary.
**write lane** — The single worker permitted to write a given artifact at a given time.
  Not a queue or a lock.
**zero backend** — Nothing runs behind the agent: no scripts, daemons, services, or generated state machinery.
  Not nothing is enforced; mechanisms and judgment still bind.
**zero test** — The pre-fan-out check of zero overlap, zero risk, zero friction.
  Not a gate that runs after the work; it decides whether to fan out at all.
