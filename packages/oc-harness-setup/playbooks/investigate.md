### Investigate

**You own the answer. Read the code, gather evidence, and report. Change nothing.**

2. Name what a useful answer will contain.
3. Find the files the question is about.
4. Read those files from the start to the end.
5. Trace how data enters, moves through, and leaves them.
6. Run a check for each claim you want to make.
7. Record the command, its exit code, and the key output line beside each finding.

9. Write the answer as an overview, key ideas, how it works, where it lives, and gotchas.
10. Stop and hand the task to the bug-fix or feature playbook when a code change is needed.

**Reply:** the answer, with each finding labelled proven or unverified. Say "I do not know" where evidence is missing.
