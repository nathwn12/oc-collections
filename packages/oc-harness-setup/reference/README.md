# Harness references

`AGENTS.md` is the always-loaded contract. Everything here is on-demand support; load only the file named by a matching rule or workflow.

- `canon.md` — locked research source canon and citation bar.
- `context.md` — context budget, delegation detail, mechanisms, worked examples.
- `enforcement.md` — network reach and enforcement examples.
- `flow.md` — which seat fires on which trigger, and when a new seat is earned.
- `gates.md` — the five repo-local gates the harness requires.
- `harness.md` — who writes what, what ships, how it versions.
- `hygiene.md` — scratch discipline and clean-pass proof.
- `memory.md` — session and harness memory ownership and format.
- `models.md` — bulk-vs-verdict tiering, binding, and catalog for the doctor check.
- `phases.md` — context moves at phase boundaries.
- `repos.md` — repo lifecycle, location, commits, delivery, CI policy.
- `tools.md` — host-tool registry; native only when listed here.
